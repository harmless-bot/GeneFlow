## 2024-08-11 - Focus Visible Styles for Range Inputs
**Learning:** When adding focus-visible styles globally, it is important to check if there are inputs like range sliders that might have had their focus styles intentionally removed for visual reasons. Sometimes it is better to provide a subtle focus indicator rather than relying solely on the default browser outline.
**Action:** Always verify keyboard focus states across all interactive elements (buttons, text inputs, range inputs) when adding global focus-visible styles.
