## 2026-10-03 - Semantic Forms Insight
**Learning:** Proper linkage between `<label>` and input elements via `htmlFor`/`id` is crucial for form accessibility, ensuring screen readers can correctly associate text with interactive fields. Additionally, ARIA attributes improve context for terminal-like inputs.
**Action:** Consistently use standard `<label>` tags instead of generic `<span>` elements for input descriptions, and provide explicit ARIA roles/labels for non-standard inputs.
