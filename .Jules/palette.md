## 2024-10-13 - Add a11y labels to inputs
**Learning:** Add `htmlFor` to `<label>` elements that wrap inputs to increase their clickable area and accessibility. Use `aria-hidden="true"` on decorative elements. Disable buttons clearly when no valid input is present.
**Action:** Always map labels to input IDs, hide decorative icons from screen readers, and proactively disable action buttons if inputs are empty.
