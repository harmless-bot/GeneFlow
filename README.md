# GeneFlow

Interactive web simulation illustrating genetic algorithms and population-based evolutionary optimization.

## Features

- Population generation, mutation, and crossover simulation (`ga.js`)
- Interactive generation step control and fitness metric plotting (`ai.js`)

## Tech Stack

- JavaScript
- React
- Vite

## Project Structure

- `src/ga.js` - Core genetic algorithm operators
- `src/ai.js` - Simulation controller and plotting state

## Installation

```bash
git clone https://github.com/harmless-bot/GeneFlow.git
cd GeneFlow
npm install
npm run dev
```

## Scripts

- `npm run dev` - Launch local dev server
- `npm run build` - Generate production build
